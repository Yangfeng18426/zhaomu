# 拾光 · 私人灵感手账

> 捡拾光阴里的光 —— 妙想、美好与追踪，陪你慢慢记录与成长。

一个**纯前端、零依赖**的 PWA 灵感手账。随手记下突发奇想、收藏生活的美好瞬间、追踪想坚持的小目标，还能用照片写视觉日记、一键导出 PDF 相片书。

✅ 可安装到手机桌面（Android / iOS）
✅ 数据 100% 本地存储，不上传任何服务器
✅ 完全离线可用
✅ 完整备份导出 / 导入（含照片）
✅ 零框架、零构建、零 CDN

**在线体验**：https://haihai09.github.io/shiguang/

---

## 为什么做这个产品

最初它只是一个「灵感随手记」HTML 文件。但在真机上使用后发现，**记录类工具的对手不是功能太少，而是打开成本太高**——于是逐步演化成今天的形态：

- **从 4 个功能页砍回 3 类记录**：待办、备忘录等"什么都能记"的功能反而稀释了核心价值，最终聚焦于「妙想 / 美好 / 追踪」三种记录，产品才有了性格
- **用真实内容代替模板内容**：金句库拒绝使用 AI 生成的"正确但无味"的句子，全部替换为有出处的真实名言（60 句，5 大主题）
- **按福格行为模型（B=MAP）加照片日志**：记录工具最重要的不是功能强大，而是"想记的时候能最快记下来"。光影页让用户随手一拍即可完成一次记录

## 技术亮点

### 1. PWA 在国产 Android（MIUI）上的可安装性 ✅

**问题**：manifest 以 Blob URL 内联时，Chrome 之外的内核（MIUI 浏览器 / Edge）不识别，无法触发"安装到桌面"；MIUI 系统层面还会拦截安装。

**方案**：
- manifest.json / sw.js / icon.svg 拆分为独立文件（而非内联 Blob）
- 配合系统权限：桌面快捷方式、自启动、省电策略→无限制

**结果**：成功安装为桌面独立应用，真机验证通过。

### 2. 本地存储架构：localStorage + IndexedDB 混合 ✅

**问题**：照片不能存 localStorage —— 约 5MB 上限，且 base64 编码膨胀 33%，存几张就会爆。

**方案**：
- 文字记录（妙想/美好/追踪）→ localStorage（`shiguang_v1`）
- 照片 → IndexedDB（存原始 Blob，不膨胀，容量数百 MB ~ GB 级）
- 拍摄即用 canvas 压缩兜底（≤1080px / JPEG 0.7）
- 导出备份时照片临时转 base64 打包进 JSON，导入时还原进 IndexedDB

### 3. Service Worker 缓存版本化与无感更新 ✅

**问题**：cache-first 策略下，发版后旧客户端永远命中旧缓存，用户看不到新功能。

**方案**：
- 缓存名版本化（`shiguang-v2`），激活时自动清理旧缓存
- HTML 导航请求用 network-first（有网先拿新版），静态资源 cache-first
- 前端检测到新 SW → `skipWaiting()` → `controllerchange` → 自动刷新，用户无感升级

### 4. 零外部依赖

单 HTML 文件 + 手写 CSS/JS（ES5 兼容），无 CDN、无框架、无构建工具。双击本地文件即可运行；部署只需任意静态服务器。

## 快速开始

```bash
# 本地预览（SW 需要 http://localhost 或 https 环境）
python -m http.server 8080
# 或任意静态服务器：npx serve .
```

部署到 GitHub Pages / CloudStudio / 任意静态托管后，用浏览器打开即可，支持"添加到主屏幕"安装为 App。
