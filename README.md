# 朝暮

一封只写给自己的日常。

朝暮是一个纯前端的私人随笔网站。手机浏览器可以直接打开，也可以添加到主屏幕。文字与照片只保存在当前浏览器，不上传服务器。

## 功能

- 记录、编辑和删除每日随笔
- 每篇随笔可选择楷体、宋体、仿宋或黑体
- 每篇随笔可添加最多 3 张本地照片
- 照片在保存前压缩至最长边 1600px
- 文字存入 localStorage，照片以 Blob 存入 IndexedDB
- 导出和导入完整备份，包含文字与照片
- PWA 离线访问和桌面安装
- 响应式手机界面，无框架、无构建步骤

## 本地运行

```bash
python -m http.server 8080
```

打开 `http://localhost:8080`。手机访问时，请使用电脑的局域网 IP，并保证设备处于同一网络。

## 数据说明

数据只存在当前浏览器。清除网站数据、卸载浏览器或更换设备前，请先从右上角菜单导出备份。

中文界面使用设备已有字体，不加载远程字体。因此楷体、宋体等字体在不同系统上的字形会略有差异。
